## Decisions
- chose a Router with one connpool.Transport per way out (global proxy / profile proxy / none / env) over one pool with a proxy switch, because the pools, lanes and warm-ups stay simple and profiles share nothing.
- chose: a refused connection (nobody listens) is retried once only; other connect failures (timeouts, unreachable) for up to 30 s. Rejected: retrying all connect failures for 30 s (broke TestForwardAnthropicBadRequestAndUnreachableUpstream and would delay local-backend errors).
- chose profile `proxy: none` = direct, ignoring the global and the environment proxy; absent = inherit. Provider-level calls (login, catalog, doctor probe) use the proxy all the profiles of the provider agree on, else the global one.
- chose to keep context-size/compaction out of the code (user's call); chose HTTP/2 health pings over shorter idle timeouts for the Windows-killed-connection problem.
