## Decisions
- chose to retry requests without streaming with the same loop as streams (extracted `runUpstream`) over a separate loop, so the rules cannot drift apart.
- chose a diff-based test selection (changed packages plus importers) over a commit-message marker for the subset, keeping only `[ci full]` and `workflow_dispatch` as explicit full triggers, as the user asked; rejected a nightly schedule (not requested).
- chose a concurrency group per commit SHA for pushes to main (cancel only for pull requests), because a cancelled run would otherwise leave its own diff untested.
- chose to log silence before a stream break (`silent for X`) to tell a health-ping close (~45 s) from a reset, rather than changing retry behaviour: a break after content cannot be retried.
- chose not to add a retry for the 90 s header timeout; no such 502 has occurred since the write-timing log was added.
