## Decisions
- chose a separate type `claude_api` over a key on `claude`: the kind (subscription or paid by token) is visible in the list and cannot be started by mistake; both share `IsOwnType`
- chose to leave `base_url` unset for the official server (the loader fills nothing in; `EffectiveBaseURL` shows it) over writing the default: `--like` and the config stay clean and Claude Code keeps its own default
- chose the env var check by line start over substring in the launch tests: the CI environment holds the commit message
- chose a fingerprint of hashes and counts (cache key prefix, system prompt, tools, item count) compared with the last request of the key, over logging text: a cache miss gets a cause and the log stays free of prompt text and ids
- rejected skipping the warm-up of an idle pool: it saves a wasted handshake but makes the first request after a pause pay for one
