## Decisions
- chose a configurable `listen.max_body_mb` (default 256) over a hard-coded larger constant: the user asked for the value to live in the config.
- chose "only the working directory's sessions" for send (the user's rule) over the latest sessions of all projects; no `--all` flag was added.
- chose a separate thin `ccgpy` binary over an argv[0] trick in ccgp: it ships through archives and npm without extra modes.
- chose max(catalog max, 922000) for GPT-6 windows over 872000 (catalog, conservative) and over 1M (nothing in the account catalog or the web supports it for the subscription backend).
- chose to fix the "1M" display in the statusline scripts (min with `CLAUDE_CODE_AUTO_COMPACT_WINDOW`) rather than in ccgp: Claude Code reports the window of the model name and ccgp cannot change that.
