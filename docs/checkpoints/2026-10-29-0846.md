## Decisions
- chose the npm organization scope `@cc-go-proxy` and the name `@cc-go-proxy/ccgp` for the main package over `@cc-go-proxy/cli`, to match the command name; one variable `NPM_NAME` in release.yml changes it.
- chose version 0.1.0 for the first release (history restarted), and made the CI install check follow the newest published release instead of a fixed version.
- chose zstd (as the official Codex client) over gzip for request compression, with a plain fallback that switches compression off only when the plain body is accepted.
- chose to retry only 502/503/504 gateway errors, not 500, and to keep the 90 s header timeout un-retried.
- chose npm 11.21.1 and Node 24.22.2 (LTS line) over npm 12 / Node 26: npm 12 disables lifecycle scripts by default, which could break the user's other projects; 11.21.1 is enough for `npm stage publish` / `npm trust`.
