## Decisions
- chose scope `@phpcraftdream` and the name `ccgp` (npm itself suggested `@phpcraftdream/ccgp` when it refused the bare `ccgp`) over `@phpcraftdream/cc-go-proxy`; one variable `NPM_NAME` in release.yml changes it.
- chose to keep the npm package at six platforms and ship the four new platforms only as release archives plus install.sh, because the first publish of many new package names from a young account risks npm's spam filter; the launcher already points to the archives.
- chose a bundled fallback root set (`golang.org/x/crypto/x509roots/fallback`, used only when the system store is empty) over documenting "install ca-certificates", for minimal containers.
- chose to soften the health ping (30/15 s) and to retry broken streams only before the client saw content, rejecting a retry after content (the Codex backend cannot resume a stream) and a parallel hedged dial for now (wait for evidence).
- chose to switch a lane to its warm pool as soon as the connection is open, instead of at the next request, because idle bare-TLS connections were aborted by software on the host (17 retries in an hour).
