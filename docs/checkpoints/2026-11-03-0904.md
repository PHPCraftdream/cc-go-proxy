## Decisions
- chose a health ping every 15 s with a 30 s answer limit (silence limit of a dead connection stays 45 s) over only changing lane choice: the ping keeps every lane's connection alive on z.ai (probe: alive at 25 s, GOAWAY at 30 s, pings every 10 s keep it for 120 s) and softens the kill threshold
- dropped remapping mid-stream `server_is_overloaded` to `overloaded_error`: Claude Code never re-runs after a completed text/tool block, so nothing is recovered; logged the phase of the break instead
- chose a detect-and-explain design for vanishing servers (run record + heartbeat mtime + stop note + job info + crash file) over trying to catch TerminateProcess, which cannot be caught
- chose to copy only the documented "Global config" UI keys into profiles, and to add them to existing profiles only when absent (a key the profile has is its own); `claudeInChromeDefaultEnabled` left out on purpose; profiles of type claude unchanged
- chose job helpers in the Windows-only file (lint `unused` on Linux) and reading the heartbeat interval where the goroutine starts (race)
