## Decisions
- chose per-rule `context_window` and a catch-all `*` rule over root-level `default_model`/`context_window`, because one root value was confusing and could not express per-model windows.
- chose the window of the rule serving the main model for CLAUDE_CODE_AUTO_COMPACT_WINDOW over the minimum of all rules, because a small Haiku window would otherwise shrink the whole session.
- chose copying shared Claude Code dirs (with a manifest) over junctions, so a session can never write into the user's own config.
- chose an Anthropic-Messages passthrough type for z.ai over the chat-completions converter, to avoid lossy conversion and match z.ai's documented Claude Code setup.
- rejected proxying a Claude subscription (credentials are never read, forwarded or stored); rejected fake credentials as a way to silence warnings in favour of documented env opt-outs.
