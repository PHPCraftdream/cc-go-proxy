# Code of conduct

ccgp is a small project run by volunteers. To keep it pleasant to work on:

- Be respectful. Disagree with ideas, not with people.
- Assume good faith, and say so when you are unsure what someone meant.
- No harassment, discrimination, personal attacks or publishing other people's private information.
- Keep issues and pull requests on topic, and be patient: maintainers reply when they can.

This applies to issues, pull requests, discussions and any other project space. Maintainers may edit, hide or
remove contributions that break these rules, and may block repeat offenders.

To report a problem, use GitHub's *Report content* on the comment or contact the maintainers through a private
[security advisory](https://github.com/PHPCraftdream/cc-go-proxy/security/advisories/new) if it is sensitive.
